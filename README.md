FinTech Dynamic Auction & Game Theory Simulation Sandbox

An interactive web-based sandbox built with Python, Streamlit, and Plotly to model auction mechanism design, dynamic settlement pricing, and behavioral bidding dynamics (such as Dollar Auction escalations and escalation traps).

Project Overview
This application provides a real-time behavioral environment for evaluating strategic bidding dynamics, order book depth, price trajectory propagation, and player irrationality traps in competitive auction settings.

Key Features
Dynamic Bidding Trajectory: Interactive real-time visualization of valuation vs. bidding dynamics using interactive Plotly charts.
Auction Mechanism Controls: Configurable parameters for order book depth, settlement node game logic, and dynamic price steps.
Risk & Settlement Dashboard: Real-time evaluation of ROI, bid escalation thresholds, and loss mitigation metrics.

Tech Stack
Framework: Python, Streamlit
Data Visualization: Plotly, Pandas
Modeling: Game Theory & Auction Mechanism Simulation
